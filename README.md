# 🌟 Tribute Website of Odisha

A responsive tribute website dedicated to showcasing the rich culture, tourism, and heritage of Odisha, India. This project was built using core web technologies with a focus on accessibility, design aesthetics, and cross-device compatibility.

## 🚀 Features

- ✅ Responsive web layout optimized for mobile and desktop
- 🎨 Cultural tribute with themed visuals and color palette
- 🧭 Smooth navigation with interactive content sections
- 📷 Image and text sections highlighting Odisha's tourism and heritage
- 🌐 Cross-browser compatibility and clean UI design

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
